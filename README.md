# Zhang Ye's Blog

个人技术博客，记录企业级系统架构、数据安全、AI 应用与数字化转型相关的实践、方法和思考。

- 在线访问：[zhangyeio.github.io](https://zhangyeio.github.io/)
- GitHub 主页：[@zhangyeio](https://github.com/zhangyeio)

## 内容方向

- 企业级系统架构与技术治理
- 数据安全、权限、审计与合规
- RAG、Agent、模型评测与 AI 工程化
- 数字化转型与复杂项目实践

## 技术栈

本站使用 [Jekyll](https://jekyllrb.com/) 与 Markdown 构建，并通过 GitHub Pages 发布。

## 本地运行

请先安装 Ruby、Bundler 和仓库依赖：

```bash
bundle install
bundle exec jekyll serve
```

默认可在 <http://localhost:4000> 预览。修改 `_config.yml` 后需要重新启动本地服务。
